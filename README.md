# Measuring Representation Reorganization from Language Models to Vision-Language Models

This repository contains the code and processed results accompanying this work.

Primary analyses are in `code/experiment_1_2_sparse_and_neighborhood.py`. Retrieval and downstream evaluations are in `code/additional_evaluations_retrieval.py` and `code/additional_evaluations_statistics.py`. Supplementary analyses are under `code/supplementary/`.

Appendix C uses separate VLM variants. Model IDs used in the analyses are listed in `results/model_ids.csv`.
